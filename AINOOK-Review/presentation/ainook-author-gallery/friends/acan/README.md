# 阿灿的小屋

从 [一些奇思妙想](http://127.0.0.1:7896/author) 进入，也可 [直接打开阿灿的小屋](http://127.0.0.1:7896/author?friend=acan)。

房间左侧可以切换「初版电竞房」和「写歌电竞房」。[初版电竞房](http://127.0.0.1:7896/author?friend=acan&scene=original) 使用原始日夜图，床头灯、两台电脑和杯子可以互动，两台电脑都亮时会出现桌边氛围光。

原有房间构图里添了麦克风和写歌手记。在浏览器里点击麦克风，会用网页合成器播放约十秒的原创旋律。麦克风是画面道具，试听由点击触发，离开页面时停止。房间里的便签和演示旋律是场景创作。
