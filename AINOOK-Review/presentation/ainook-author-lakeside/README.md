# AINOOK 作者小屋 · 湖边小屋

在项目根目录启动本机预览。

```powershell
python outputs/prototypes/ainook-author-lakeside/serve.py
```

[白天小屋](http://127.0.0.1:7894/author?theme-preview=day) · [夜晚小屋](http://127.0.0.1:7894/author?theme-preview=night) · [上一轮预览](http://127.0.0.1:7893/author)

预览沿用网站的导航、背景、日夜切换和左侧作者介绍。房间里的四处互动没有常驻标记，键盘可以通过 Tab 找到它们。日夜切换保留已展开的物件，刷新恢复初始状态。

日夜主图共用同一套百分比坐标，打包在一张保留透明通道的 WebP 内。若更换构图，可在 `room.css` 校准物件和效果的位置。在触摸设备上，目标区域最小为 44 × 44 像素。
